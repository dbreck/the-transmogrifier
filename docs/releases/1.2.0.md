The Transmogrifier 1.2.0 brings repeatable export workflows to your Mac: set a file-size budget, create responsive image packs and return to any job with its settings intact.

### New

- **File-size limits:** choose a budget for each output and a minimum quality. Outputs that cannot meet the target are reported without writing an oversized file.
- **Responsive packs:** export multiple WebP widths with optional JPG fallbacks, actual-width filenames and copyable srcset values.
- **Live comparison:** automatic previews show accurate encoded sizes, with a comparison wipe, shared zoom, 100% inspection and transparency backgrounds.
- **Batch history:** search jobs, reveal outputs, reuse settings, run again or retry unfinished variants. Cancelling keeps completed work recorded.
- **Mac workflow:** a compact layout, Command-O to add images, Command-Return to export, and optional saved-preset conversion from Finder or the Dock.

### Improved

Quality is now a direct control, PNG is clearly marked lossless, and output destinations are explicit. Preview cache size and stale-result bugs are fixed. Saved recipes retain folder permissions where available, existing presets keep their encoder quality, and earlier conversion history remains available.
